# 2026-08-13 QQ 新 API 补齐计划

## 1.1.0 范围

- 版本从 `1.0.23` 升级至 `1.1.0`。
- 本版本只实现 QQ 官方 V2 流式消息、指令面板、单聊全局自定义菜单和对应 Console 管理页面。
- 群成员详情、分享链接、订阅消息授权事件、输入状态通知、互动召回和图片校验等 API 延后处理。

## 流式消息

- 提供官方 V2 单聊流式内部 API `bot.internal.sendStreamMessage()`，对应 `POST /v2/users/{user_openid}/stream_messages`。
- 提供高层 `bot.stream()` 会话对象，由调用方通过 `write()` 连续写入生成片段，并通过 `end()` 发送完成包；会话自动维护 `stream_msg_id`、`index` 和被动回复字段。
- 默认消息策略为普通发送，以保证成功率。
- 配置保留三种流式能力：私聊官方 V2、私聊旧版兼容、群聊旧版兼容。旧版兼容能力默认关闭并标注为非当前公开 API 保证范围。
- V2 默认策略可选普通发送、立即完成、模拟逐段；模拟逐段默认每 80 字、200 毫秒，明确标注额外延迟与失败风险。

## 指令面板和菜单

- 增加强类型内部 API：指令面板列表、创建、详情、修改、删除、关联对象，以及单聊全局自定义菜单查询和修改。
- 通过配置总开关启用 QQ 指令面板。关闭时不注册 Console 页面、不创建数据库记录、不调用面板 API。
- 启用时只同步 Koishi 顶层且 `slash=true` 的命令，默认支持 `c2c` 和 `group` 场景。
- 支持手动选择排序、字典序前 20、字典序后 20、随机 20 四种模式。自动模式在适配器就绪后同步，随机模式在每次插件加载或重载时重新选择。
- 手动模式由 Console 页面按 QQ Bot 持久化命令选择、顺序和场景，预览后手动同步。
- 命令名或描述超过 QQ 限制时跳过并显示原因；不自动截断。
- 只管理 `remark` 带适配器专属标记的面板，绝不修改用户自行创建的面板。
- Console 页面同时提供全局自定义菜单的查询、编辑、预览和手动同步，权限等级为 3。
